# Agent Instructions

## General Instructions

- Keep responses concise and avoid narration. Add a TLDR for long responses
- No emdashes, no emojis
- Use the question tool when prompting/asking the user a question. Always discuss plan/architecture before implmentation if unsure, do not guess the user's request.

## Coding Standards

- Use ruff to lint and format
- Add short docstrings where needed (eg. functions, classes)
- Keep comments short and concise, code says what, comment says why for non-obvious behavior
- Use conventional git commits, prefer multiple small commits over single large commit.
